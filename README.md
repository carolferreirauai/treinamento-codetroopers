## 👾 Treinamento CodeTroopers - C++

### 📌 Sobre o Repositório
Este repositório armazena todos os códigos, exercícios e pequenos projetos desenvolvidos durante o meu período de treinamento na **CodeTroopers**. 

O objetivo principal deste material é o aprimoramento da lógica de programação, resolução de problemas e o estudo aprofundado das estruturas e sintaxe da linguagem **C++**.

### 🚀 Tecnologias Utilizadas
* **Linguagem:** C++
* **Compilador Recomendado:** GCC / MinGW.

### 👩‍💻 Desenvolvedora

### 💡 Como Executar
Para compilar e rodar os códigos deste repositório no terminal:
1. Navegue até a pasta do arquivo: `cd nome-da-pasta`
2. Compile o código: `g++ nome-do-arquivo.cpp -o executavel`
3. Execute o programa: `./executavel` (no Linux/Mac) ou `executavel.exe` (no Windows)
